# GEM UI fonts

`AovelSansRounded.ttf` — *Aovel Sans Rounded* by Aovel.

- License: Freeware
- Source: https://www.fontspace.com/aovel-sans-rounded-font-f12477

Loaded at runtime by the FreeType-backed font module (`gem/font.c`); it is the
default window-title / `v_gtext` face in the SDL testbed. Drop additional TTF/OTF
faces here and open them with `font_open()`.
